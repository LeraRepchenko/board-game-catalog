\# BoardGameCatalog



Сквозной проект. Вариант 16: Каталог настольных игр.



\## Этап 1. Каркас приложения



Реализовано:

\- Главное окно QMainWindow с меню и панелью инструментов.

\- Форма добавления игры: название, число игроков, время партии, сложность, описание.

\- Статус-бар для обратной связи.

\- Горячие клавиши: Ctrl+N (добавить), Ctrl+Q (выход).

\- Валидация: пустое название → предупреждение.



\## Сборка



1\. Открыть BoardGameCatalog.pro в Qt Creator.

2\. Собрать (молоток).

3\. Запустить (зелёный треугольник).



\## Технологии



\- Qt 6.11.2, MinGW 13.1.0, qmake.

\- QMainWindow, QMenuBar, QToolBar, QStatusBar, QFormLayout, QGroupBox.
