# BoardGameCatalog

Сквозной проект. Вариант 16: **Каталог настольных игр**.

Приложение на Qt Widgets для ведения каталога настольных игр: добавление, хранение, поиск и редактирование записей.

## Этап 1. Каркас приложения

### Что реализовано
*   **Главное окно (QMainWindow):** меню, панель инструментов, статус-бар.
*   **Форма добавления игры:** название, число игроков, время партии, сложность, описание.
*   **Валидация:** проверка на пустое название.
*   **Горячие клавиши:** `Ctrl+N` (добавить), `Ctrl+Q` (выход).
*   **Артефакт 1: Автосохранение через QTimer.** Таймер с интервалом 60 секунд вызывает слот `onAutosave()`.
*   **Артефакт 2: Логирование действий через лямбда-слоты.** Все клики пишутся в консоль в формате `[LOG] действие`.


## Этап 2. Адаптивный интерфейс (Артефакт: Главный интерфейс проекта)

### Что реализовано
*   **Адаптивная форма на QFormLayout:** поля ввода организованы в две колонки (метка — поле).
*   **QVBoxLayout и QHBoxLayout:** главный слой окна вертикальный, панель кнопок и строки с короткими полями — горизонтальные.
*   **Кнопки действий:** «Добавить», «Удалить», «Сохранить», «Настройки», «Очистить».
*   **Пружины addStretch():**
    *   Прижимают короткие поля (Игроков, Время) к левому краю.
    *   Прижимают панель кнопок к правому краю окна.
*   **Политики QSizePolicy:**
    *   Поле «Описание» имеет политику `Expanding` по вертикали и горизонтали — забирает всё свободное место при растяжении окна.
    *   Короткие поля имеют политику `Fixed`.
*   **Обработчики кнопок:** у каждой кнопки есть свой слот (`onAddGame`, `onDelete`, `onSave`, `onSettings`), действия логируются в консоль.

### Связь с лабораторными работами
*   **ЛР2:** безопасное управление памятью (все виджеты с родителями).
*   **ЛР3:** логирование действий через лямбда-слоты, автосохранение.
*   **ЛР4:** адаптивная компоновка (`QSizePolicy`, `addStretch`, `QFormLayout`).

## Стек технологий
*   Qt 6.11.2, MinGW 13.1.0, qmake, C++17.
*   QMainWindow, QMenuBar, QToolBar, QStatusBar.
*   QFormLayout, QVBoxLayout, QHBoxLayout.
*   QSizePolicy, addStretch().
*   QTimer, лямбда-слоты.

## Сборка и запуск
1. Открыть `BoardGameCatalog.pro` в Qt Creator.
2. Собрать проект (молоток).
3. Запустить (зелёный треугольник).

## Пример работы

### Запуск и автосохранение
```
[TIMER] Автосохранение запущено (интервал 60 сек)
```
*Каждые 60 секунд:*
```
[AUTOSAVE] Данные сохранены в 14:35:22
```

### Нажатие кнопок
```
[LOG] Нажата кнопка «Добавить»
[LOG] Игра «Каркассон» добавлена (2 игроков, 60 мин, Лёгкая).
```
```
[LOG] Нажата кнопка «Удалить»
```
```
[LOG] Нажата кнопка «Сохранить»
```
```
[LOG] Нажата кнопка «Настройки»
```

### Валидация
```
[LOG] Ошибка: пустое название игры
```
*Появляется диалог «Введите название игры».*
