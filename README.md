# BoardGameCatalog

Сквозной проект. Вариант 16: **Каталог настольных игр**.

Приложение на Qt Widgets для ведения каталога настольных игр: добавление, хранение, поиск и редактирование записей.

## Этап 1. Каркас приложения

### Что реализовано

**Главное окно (QMainWindow):**
- Меню «Файл» (Добавить игру, Выход) и «Справка» (О программе).
- Панель инструментов: Добавить, Очистить, Выход.
- Статус-бар для обратной связи.

**Форма добавления игры (QFormLayout):**
- Название (QLineEdit).
- Число игроков (QSpinBox, 1–20).
- Время партии (QSpinBox, 5–600 мин).
- Сложность (QComboBox: Лёгкая, Средняя, Сложная).
- Описание (QTextEdit).

**Валидация:**
- Пустое название → предупреждение.
- Корректные значения спиннеров.

**Горячие клавиши:**
- `Ctrl+N` — добавить игру.
- `Ctrl+Q` — выход.

**Артефакт: автосохранение через QTimer.**
- Таймер с интервалом 60 секунд запускается при старте приложения.
- Каждые 60 секунд вызывается слот `onAutosave()`, сохраняются данные, в статус-бар выводится сообщение.

**Артефакт: логирование действий через лямбда-слоты.**
- Каждое действие пользователя (кнопка, меню, панель инструментов) пишется в консоль.
- Формат: `[LOG] 12:34:56 — действие`.

### Связь с лабораторными работами

- **ЛР2 (дерево объектов QObject):** все виджеты созданы с родителем, при закрытии окна удаляются автоматически.
- **ЛР3 (QTimer, лямбда-слоты):** автосохранение через `QTimer`, логирование через лямбда-слоты.

### Критерии приёмки (выполнено)

- ✅ Программа компилируется и запускается.

## Сборка и запуск

1. Открыть `BoardGameCatalog.pro` в Qt Creator.
2. Собрать проект (молоток в левом нижнем углу).
3. Запустить (зелёный треугольник).

## Пример работы

### Запуск приложения

В консоль выводится:
```
[TIMER] Автосохранение запущено (интервал 60 сек)
```

### Добавление игры

Нажатие «Добавить игру» с названием «Каркассон»:
```
[LOG] Нажата кнопка «Добавить игру»
[LOG] Игра «Каркассон» добавлена (2 игроков, 60 мин, Лёгкая).
```

### Очистка формы
```
[LOG] Нажата кнопка «Очистить форму»
[LOG] Форма очищена
```

### Работа с меню
```
[LOG] Меню: Файл → Добавить игру
[LOG] Меню: Справка → О программе
```

### Автосохранение (каждые 60 секунд)
```
[AUTOSAVE] Данные сохранены в 14:35:22
```

### Валидация
```
[LOG] Нажата кнопка «Добавить игру»
[LOG] Ошибка: пустое название игры
```
Появляется диалог «Введите название игры».

### Закрытие окна
```
[DESTROY] MainWindow
```
